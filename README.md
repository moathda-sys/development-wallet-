# محفظة التطوير الأسبوعية
موقع مستقل بصفحتين داخل واجهة واحدة: المحفظة والتحليل. دون خادم ودون مكتبات خارجية.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا مثل `development-wallet` (مستقل عن مستودع المهندس).
2. ارفع هذه الملفات إلى الجذر: `index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. الرابط: `https://USERNAME.github.io/development-wallet/`.

## الاستخدام
- 6 جلسات إنجليزية × 45 دقيقة، والجمعة راحة.
- Excel/P6: ساعة أسبوعيًا، 1–2 جلسات.
- AI والمعرفة والكورسات: 3 ساعات لكل مجال، 2–4 جلسات.
- اضغط + جلسة بعد الإنجاز وأدخل اسم ما تعلمته (اختياري).
- تبويب التحليل يعرض المعدلات والسجل الأسبوعي وأداء الأقسام.
- البيانات تحفظ في localStorage على المتصفح فقط، وتصدير نسخة JSON متاح من الواجهة.

تنبيه: لا توجد مزامنة بين الأجهزة. لا تمسح بيانات Safari قبل تصدير نسخة احتياطية.
